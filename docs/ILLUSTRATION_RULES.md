# イラストの決まり（人のイメージ図）

サイト内で、絵の雰囲気をそろえるための決まり。新しい図を作るときは、これに合わせる。
見本は、開発サーバーの `/editor/figures`（全図の一覧。`?ids=st23,st24` で絞れる）で見られる。

## 1. 人の描き方（ちびキャラ）
- 約2.5頭身。頭は大きめ、手足は短め。骨組み（関節の位置）は `src/lib/figure.ts` の `BODY`、描き方は `IllustrationView.tsx` の `Person`。見た目を変えるときは、この2か所だけを直す（図のデータは直さなくてよい）。
- **顔**：点の目、小さな笑った口、うすいほほ。**全員やさしい笑顔**にそろえる（表情は変えない）。顔は、頭の向きに合わせて回る（前屈・仰向けでも、正しい向き）。
- **髪**：こげ茶。「short」（既定）と「ponytail」の2種類だけ。ペアの2人を見分けたいときに、片方をポニーテールにする。
- **服**：半袖シャツ（人の色）＋短パン（同じ色の濃い色）＋白いくつ。肌は1色。
- **輪郭線**：すべて、同じ色・同じ太さ（`OUTLINE`）。奥側の手足は、少し暗い色にする（手前との区別）。
- **ゼッケン**：番号や記号は、胸の白い丸に出す（頭には出さない）。
- 向き：横向きが基本（右向き）。左向きは「反転」。「正面」は、足を描くチェックを外す（目が中央に、くつは左右へ）。

## 2. 色の役割（`ColorName`）
| 色 | 使いどころ |
|---|---|
| 青 | 主役（練習者・「自分」） |
| オレンジ | 相手・ペア・ノッカー |
| 緑 | 3人目・補助役 |
| 赤 | 4人目（4人以上のときだけ） |
| グレー | 待っている人・列 |

## 3. 図の約束
- 大きさ：320×200。床の線は y=172。人は `person()` で作り、足が床に着くよう高さをそろえる（`groundedY`）。標準の大きさは 1.2〜1.4。1つの図で複数人なら、同じ大きさにそろえる。
- 題名（1行、上中央、y=14）は、動作を、やさしい文で。説明を足す文字は、小さく（size 10）。
- 矢印：**赤の実線＝体を動かす向き**、**グレーの破線＝移動・物の動き**、**黄の破線＝シャトルの軌道**。
- 役名は、人の足元（y=186）に書く。

## 4. ペアの図の決まり
- 主役は左（青・右向き）、相手は右（オレンジ・左向き）が基本。向かい合う図は、お互いに向き合わせる。同じ向きに立つ図（うしろから引くなど）は、どちらも右向き。
- **手を相手に触れる位置は、計算で合わせる**：`reach(人, "R"|"L", 位置)`。位置は、相手の `joint(人, "wristR")` などで取る。手が空中に浮いたり、体に刺さったりしないようにする。
- 触れ合う場所：手のひら＝手のひら（手押し相撲）、手＝手首（腕を引く）、手＝足首・ひざ（脚を支える）、背中＝背中（背中合わせ）。
- 奥行き：片方が手前にいるときは、手前の人の床を低く（`ground: 188` など）して、少し小さく描く。
- 触れ合う2人は、体が重なりすぎないようにする。重なるなら、手前の人を、あとの順に置く。
- ポーズの追加：`poses.ts` に、ペア用のひな型（`sitLeanForward`・`sitLeanBack`・`armsBehind`・`pushStance`）を入れてある。足りなければ、同じ形で足す。

## 5. 描いたあとの確認
- `/editor/figures` で、見た目を確認する（顔が頭の向きに合うか、手足が床・相手に合っているか、図からはみ出していないか）。
- 公開される図は、メニューが「運営者確認済み」になったものだけ。
