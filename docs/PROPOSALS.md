# 追加コンテンツ・改善の提案（2026年10月13日）

優先順に並べています。「確認できたこと」と「私の推測・一般的な情報」を、分けて書きました。

## 1. 指導者にとって有用なサイトになるか

**現状の評価**：メニューの量（420件）と、図・手順・声かけまで書いてある点は強み。ただし、公開されているメニューは、確認済みの3件だけ（`d01`・`d02`・`d12`）。**使える状態にするには、運営者の確認作業が先**。

### 追加すると効果が大きいもの
1. **練習プラン例（そのまま使える1日の流れ）**：「小学生クラブ90分」「中学部活120分」「少人数（4人）」「コート1面で12人」など。既存のメニューを並べるだけで作れる。指導者の一番の悩みは「今日、何をするか」なので、検索にも強い。
2. **人数・コート数に合わせた回し方**：体育館が狭い、人数が多い、といった場面の運営ノウハウ。運営者の経験が出る内容で、他のサイトと差がつく。
3. **審判・ルール入門（運営者は公認審判員）**：コールとハンドシグナル、サービスの判定、15点制の早見表、スコアシートの書き方。プロフィールの強みと一致する。
4. **指導の声かけ集**：「ネット前のミス」「フォームが崩れたとき」など、状況別の声かけ。メニューの「よくあるミス」を、横断して引けるようにする。
5. **印刷用シート**：1枚に、コート図・手順・ポイントが入ったA4。今の「プラン」の印刷を、さらに整える。
6. **保護者向けの案内**：始め方、費用の目安、用具の選び方。用具の選び方は、アフィリエイトとも相性がよい。
7. **クイズの拡張**：チーム対抗用の印刷版、月ごとの追加。

### 改善したほうがよいもの
- 公開メニューが少ないと、トップが寂しい。**まず、よく使われそうな30〜50件を確認して公開する**のがおすすめ（ダブルス・股関節の追加分も含む）。
- 追加した150件は、AIが書いた下書き。**運営者が読んで、直した内容だけを公開する**（この方針は、そのままで正しい）。

## 2. 運営者が稼げる仕組みはあるか

**あるが、すぐには大きく稼げない**、というのが正直な見立て。

- **すでにあるもの**：用品ページの「おすすめ商品」に、アフィリエイトのチェックがあり、チェックすると「PR」表示と注意書きが出る。公式ページへのリンク方針。
- **足りないもの（運営者の作業）**：アフィリエイトの登録と、商品ごとの広告リンクの取得（A8.net、もしもアフィリエイト、Amazonアソシエイト、楽天など。条件は各社の最新を確認）。
- **Amazonアソシエイトの条件（検索で確認）**：登録後180日以内に、3件の適格な販売が必要とされている（自分の購入は数えない）。
- **現実的な順番**：
  1. 保護者向け・初心者向けの用具記事（ラケット、シューズ、シャトル）を作る（成約に近い）。
  2. 指導者向けの本・DVDの紹介を、書評つきで載せる。
  3. （任意）練習プラン集のPDFを、BOOTH・noteなどで販売する。広告ではなく、直接の収益になる。
- **注意**：検索で見つけてもらえるまで、時間がかかる。収益の保証はない。広告表示のルール（景品表示法のステルスマーケティング規制）を守る（いまの「PR」表示は、その方向）。

## 3. Google AdSense の審査に通るか

**通る保証はなく、いまの状態では、通りにくい可能性が高い**（私の見立て。審査はGoogleが行い、基準は変わる）。検索結果で確認できた、一般的な要件と、いまの状態：

| 要件 | いまの状態 |
|---|---|
| 独自ドメイン | 未取得（取得後に `NEXT_PUBLIC_SITE_URL` を設定） |
| プライバシーポリシー | あるが、「広告配信は利用していない」と書いてある。**広告を入れるなら、書き換えが必要** |
| 運営者情報・お問い合わせ | ページはある。運営者名・Googleフォームが未設定 |
| 内容の量と独自性（「有用性の低いコンテンツ」を避ける） | 公開が3件だけ。**公開メニューを増やすのが先** |
| 運営者の経験・一次情報 | プロフィールあり。メニューに、運営者の経験談や、実際にやった感想を足すと強くなる |
| テキストの充実 | 図が多いサイトは、説明文が薄いと不利。各メニューの「ねらい・手順・ミス」は、強み |

**AI下書きについての注意**：量を増やしただけのAI文章は、評価されにくいと言われる。運営者が確認し、経験を足して公開するのが安全。

### 先にやるとよい順番
1. メニュー30〜50件を確認して公開、雑学・ルール・クイズも確認する。
2. 独自ドメインを取得して、公開する。
3. 運営者名・プロフィール・Googleフォームを設定する。
4. 練習プラン例と、審判入門などの記事を、数本足す。
5. その上で、AdSenseに申請する（広告を入れる前に、プライバシーポリシーを書き換える）。
