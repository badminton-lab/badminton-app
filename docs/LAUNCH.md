# 公開までの手順と工数（概算）

作成：2026年10月19日。工数は、コードの量と「メニュー1件あたり3〜5分で確認する」前提の概算。運営者のペースで変わる。

## 決まっていること（2026年10月19日）
- 最初は、運営者が確認した**約100件のメニュー**に絞って公開する。残りは、公開後に少しずつ確認して増やす（確認済みだけが公開される仕組みなので、そのまま使える）。
- ホスティングは、**プッシュで自動公開されるもの**（Vercel など）にする。エディタの「公開する」ボタンが、データをコミット・プッシュして、自動で作り直される。
- **アクセス解析は、最初から入れる**。広告・アフィリエイトは、後から。
- 解析の種類は、**未決**（下の「アクセス解析」を参照）。

合計（約100件で公開する場合）：運営者 約25〜45時間、Claude Code 約5〜10時間。

## Claude Code にお願いできること／できないこと
- **できる**：コード・設定の変更、ビルドと自動チェック、公式情報の調査と下書き、誤字や数字の食い違いの点検、手順書づくり、公開後の修正とメニュー追加、アクセス解析の導入（コード側）。
- **できない（運営者の作業）**：ドメイン・ホスティング・Google などのアカウント作成、契約、支払い／内容の最終確認と「確認済み」の判断（運営者の経験がこのサイトの価値）／法的な最終判断／スマホ実機・印刷の確認。

## アクセス解析（最初から入れる）
- 入れるときに、必ず必要になる作業：①プライバシーポリシーの書き換え（今は「広告配信は利用していない」「解析は使っていない」の趣旨になっている）、②CSP（`next.config.ts` の `script-src`・`connect-src`）に、解析の送信先を追加、③お問い合わせ以外の外部通信が増えることの確認。
- 候補（公式の説明で、価格・個人情報の扱いを確認してから決める）：ホスティング付属の解析（Vercel の Web Analytics など）、Cloudflare Web Analytics、Google アナリティクス、Plausible など。個人を特定しない・Cookie を使わない方式のほうが、プライバシーポリシーの書き換えが少なく済む。
- 選ぶ前に決めること：見たいもの（ページごとの閲覧数・検索語・メニューのお気に入り数など）、費用。

## 公開前に決めること（`QUESTIONS.md` の #1〜#5）
運営者名、Google フォームの URL、公開 URL（ドメイン）、アフィリエイトの要否（後からに決定）、他社ラケットの掲載。

### Google アナリティクス（GA4）を使う場合（2026年10月19日に検討）
- 無料。見られるもの：訪問者数・ページごとの閲覧数・流入元・国・端末など（Vercel/Cloudflare と同じ）に加えて、サイト内検索の語（`?q=` の検索。自動計測の対象だが、このサイトの検索で実際に取れるかは、導入後に確認が必要）、外部リンクのクリック、お気に入り・プラン追加などの独自イベント（コードで送る）。個別のデータの保存期間は、標準で最長14か月（公式の資料）。
- 導入時の作業：Google のタグを入れるコード、プライバシーポリシーの書き換え（Cookie・外部送信・送信先・目的）、CSP の許可先の追加（`script-src`・`connect-src`・`img-src`。Google の公式の案内で、許可するドメインを確認してから）。
- 日本の外部送信規律（電気通信事業法）の対象になるかは、法的な判断。確認できていないので、少なくとも、公表（プライバシーポリシーなど）は行う前提にする。
